# 余光

一款让书页与真实世界保持连接的沉浸式 macOS 阅读应用。

当前版本是 `0.6.2` 交互原型，已形成从氛围首页、本地导入、书架管理、书脊打开到
沉浸阅读显示调节的完整本地闭环。

## 运行

```bash
npm install
npm start
```

打包 Apple Silicon macOS 应用：

```bash
npm run package
```

## 当前包含

- 可切换四种静谧景观的无窗框首页；高密度白色 Balancing 点阵固定居中，仅悬停后右向逐字提示
- 无传统页眉的拟真书架与窗外现实场景
- 书架底部胶囊集中搜索、导入、背景图与 UI 配置；无操作 30 秒后自动返回首页
- 竖向拟真书脊直接展示书名与作者，并以细小书签标记最近阅读
- 左侧书架立柱上的木质管理标签，进入居中的正面书封管理视图
- 管理视图支持搜索、Markdown/TXT/PDF/EPUB 导入和本地书删除；内置样书只读保留
- 基于内容指纹跳过重复导入，书籍元数据与正文分开按需读取
- 拖放导入与持久化书架
- 同一时间轴上的抽书、开书、全屏展开与合书返回动效
- 弱化书壳拟真、收紧版心和默认字号的全屏双页阅读界面
- 纸张内部只显示正文与页码，不再显示运行页眉、章节标签或大标题
- 使用 WebGL 连续纸面网格实现斜向卷曲、纸背透印与动态投影；拖拽可停、可逆、可取消，落页无回弹
- 分帧、可取消且带上限版式缓存的动态分页；首屏可先于全书整理完成展示
- 页边直接拖拽、鼠标轻点、方向键、空格和底部胶囊共用同一卷页模型，`Esc` 按控制层级退出
- 唯一的底部居中长胶囊承载返回、翻页、进度、目录、书签、显示和声音；
  已保存位置以可点击的 `📌` 直接标在阅读进度条上
- 进度、目录与显示配置共用胶囊上方唯一的居中玻璃面板，不使用侧边浮层
- 显示面板支持手动输入本地字体、12–32 px 字号、前景色与背景色
- 显示偏好和每本书的逻辑阅读位置本地保存，`⌘,` 打开居中显示面板
- macOS 原生菜单与 `⌘O`、`⌘D`、`⌘T` 等快捷键
- 跟随系统“减少动态”设置的降级动效
- 四段 CC0 真实翻书录音、双向随机变化与弱化声音开关

## 产品边界

当前方向聚焦本地、沉浸、安静的阅读体验，不包含 AI、文字朗读和跨设备同步。

- Markdown 与 TXT 单本不超过 2 MB；只做编码、换行、明确硬换行和中文软折行等
  高置信度修复，不改写正文语义
- Markdown 按 CommonMark/GFM 语法树读取标题、嵌套列表、任务项、表格、引用、
  行内/块级代码和数学公式；代码高亮、公式排版与阅读字体配置会在重新分页后保留
- PDF 单本不超过 64 MB、2,000 页；读取无密码 PDF 的文本层，不包含扫描页 OCR，
  复杂分栏、公式和原始版面只做阅读化重排
- EPUB 单本不超过 32 MB；读取未加密、可重排的正文和目录，不保留原书 CSS、
  图片、媒体、脚本与固定版式

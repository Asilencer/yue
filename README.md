# 余光

一款让书页与真实世界保持连接的沉浸式 macOS 阅读应用。

当前版本为 `0.6.2`，产品方向聚焦本地 EPUB 导入、可重排正文和全屏连续阅读。

## 运行

需要符合 `^20.19.0 || >=22.12.0` 的 Node.js。

```bash
npm install
npm start
```

打包 Apple Silicon macOS 应用：

```bash
npm run package
```

## 当前包含

- 四种可切换的明亮景观首页，以及进入书架的轻量过渡动效
- 卡片式书架、书名与作者搜索、在读/已读分类和本地图书删除
- 八个内容互不重复、可移出书架的内置试读片段
- 文件选择和拖放导入 EPUB；元数据与正文分开存储并按需读取
- 以标题、作者和规范化正文生成内容身份；只跳过内容完全相同的重复书籍
- 全屏单列连续阅读，开书动效只作为书架到正文的过渡
- 左侧阅读缩略条、逻辑文字进度、章节目录和可点击 Pin
- Pin 和阅读进度使用文字锚点保存，字体及窗口重排后仍能回到原文位置
- 阅读显示支持本地字体、12–32 px 字号、行距、字体颜色和纸张颜色
- 可关闭的轻量开书/合书声音
- macOS 原生菜单与 `⌘O`、`⌘D`、`⌘T`、`⌘,` 等快捷键
- 可见且可关闭的操作反馈；批量导入失败时保留逐文件错误列表
- 跟随系统“减少动态”和“减少透明度”设置进行视觉降级

## EPUB 支持与安全边界

- 只支持扩展名为 `.epub` 的未加密、可重排 EPUB
- 明确拒绝 DRM/加密正文和固定版式 EPUB；`linear="no"` 资源不进入主阅读流
- 忽略目录中的外部、片段和失效链接，不因辅助导航链接中止整本书导入
- 保留标题、列表、引用、代码、显式换行和表格表头语义
- 支持带 TeX annotation 的 MathML，以及分数、根式、上下标等常见 MathML 结构
- EPUB 压缩文件上限为 128 MB，ZIP 条目数上限为 10,000
- 单个条目解压后上限为 24 MB，所需条目累计上限为 192 MB，异常压缩比会被拒绝
- 单个 OPF、导航或 XHTML 正文上限为 8 MB，避免在界面线程解析异常大文档
- 解压使用异步接口，章节转换之间主动让出界面线程

## 本地数据

- 图书元数据和正文分别保存在 IndexedDB
- 阅读显示、进度、Pin、已读状态和最近阅读记录保存在 localStorage
- 删除图书时同步清理正文、进度、Pin、已读状态和最近阅读引用
- 新增图书使用 IndexedDB `add`；只有正文结构完全一致的已知记录允许原位更新
